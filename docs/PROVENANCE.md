# Provenance

Every file in this repo, mapped back to where it was found. `Origin` is the path inside the consolidated dump: `worlds/<instance>-<world>/computer<id>/<name>` for in-world programs, `dev/` for the VS Code working folder, `legacy/` for pre-1.8 ComputerCraft and OpenPeripheral finds.

`Date` is the file's last modification time. Duplicates across backup copies of the same world were collapsed by content hash; where two copies genuinely differed, both are kept under distinct names.
